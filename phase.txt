TASK — REPLACE SEPARATE HR + SERVICES DASHBOARDS
WITH ONE UNIVERSAL ERP DASHBOARD

Work on the EXISTING ERP application.

The application currently has module-oriented dashboard concepts such as:

HR Dashboard
Services Dashboard

This architecture must now be changed.

FINAL PRODUCT REQUIREMENT:

There must be ONE UNIVERSAL ERP DASHBOARD for the logged-in user/company.

DO NOT maintain separate:

HR Dashboard
Services Dashboard
Finance Dashboard
Inventory Dashboard
etc.

Future modules must CONTRIBUTE content into the same universal dashboard.

==================================================
1. PRODUCT DECISION
==================================================

The ERP has ONE Dashboard.

Conceptually:

ERP Dashboard
   ├── Personal / My Day
   ├── HR contributions
   ├── Services contributions
   ├── Future Finance contributions
   ├── Future Inventory contributions
   └── Shared activity / attention / notifications.

Dashboard content is dynamically composed based on:

Company Module Enablement
AND
Permission Grants
AND
Permission Scope
AND
Employee Link
AND
Record Access
AND
Current Company.

NO role-based dashboard variants.

  Dashboard

  Services / Dashboard
